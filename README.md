# Noctis Theme Atelier

A responsive, static theme concept storefront.

## Features
- Responsive design for mobile and desktop
- Six concept theme cards
- Filter by Dark, Minimal, Nature
- Save/favorite themes using local browser storage
- Detail preview modal
- Wallpaper editorial section
- No build step or dependencies

## Run
Open `index.html` locally or host with GitHub Pages.

## Important
This is a visual theme catalog and preview storefront. It does not currently provide paid checkout, downloadable theme bundles, or automatic device theme installation. Actual device customization depends on device brand, OS version, and launcher compatibility.

## Deploy with GitHub Pages
1. Repository Settings → Pages
2. Build and deployment source: Deploy from a branch
3. Branch: `main`, folder: `/(root)`
4. Save and wait for the Pages URL to appear.
